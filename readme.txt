Sell boards, panels and tiles by area: linked pieces and square metre inputs, price per square metre and paid samples.

== Description ==

Coverage Calculator is for shops that sell boards, panels or tiles by the piece while customers think in square metres.

* Set the area one unit covers on the product, or per variation.
* The product page gets an area field linked to the quantity: type square metres and the number of pieces is calculated, rounded up to a whole piece; change the pieces and the area follows.
* The price per square metre is shown under the price.
* The covered area is shown in the cart and checkout (classic and block checkout) and saved on the order.
* The lowest price per square metre is stored on the product so catalogue filters can use it.
* Paid samples: a button on the product page adds a separate "Sample" line per product or variant, with its own price, a per-order limit and a shipping class.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/coverage`, or install it from Plugins, Add New.
2. Activate it. WooCommerce must be active.
3. Go to WooCommerce, Coverage Calculator, to set the unit and the sample options.

== Frequently Asked Questions ==

= Does it require WooCommerce? =

Yes.

= Where do I set how much one board covers? =

On the product edit screen, General tab, "Coverage per unit". Variations can set their own value; empty uses the product value.
